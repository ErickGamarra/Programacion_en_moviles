# Descripción del Proyecto

Aplicación Android nativa desarrollada para explorar los fundamentos del desarrollo declarativo con Jetpack Compose, configuración del entorno Android Studio y control de versiones con Git/GitHub.

# Conceptos y Componentes Utilizados

@Composable: Anotación que define funciones declarativas para la construcción de interfaces de usuario.
Column: Contenedor estructural que organiza verticalmente los elementos visuales sin solapamientos.
Text y fontSize = 24.sp: Elemento para renderizar texto utilizando unidades escalables independientes del dispositivo (Scale-independent Pixels).
Button (Material 3): Componente interactivo integrado como reto autónomo.
Theming (Color.kt y Theme.kt): Personalización de la paleta cromática del tema base mediante códigos ARGB y desactivación de colores dinámicos del sistema.
